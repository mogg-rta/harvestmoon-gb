# 仕組み：作物と手伝いの出荷

時計グリッチで日を飛ばしている間に、コロボックルが畑の作物を育てて出荷する仕組みをまとめた資料です。牧場主の条件の「出荷 5000」とお金を、卵のグリッチを使わずに作るのに使います。種を増やす種グリッチも扱います。日本語版 GB の逆アセンブルを読んだ結果と、実機で確かめた結果によります。番地の書き方は [クリアの条件と評価](10_仕組み_クリアの条件と評価.md) の 1. にあります。

## 1. 結論

- 時計グリッチで飛ばした日も、畑は1日ずつ進む。作物はコロボックルが水をやって育ち、実ったらその場で出荷される。
- 出荷は手で出荷箱に入れたときと同じに数えられ、牧場主の判定（出荷 5000）に入る。代金は経過時間の画面のあとに所持金へ入り、99999G で止まる。
- トマトは収穫のあとにまた実る。夏1日に植えて飛ぶと、1マスから 6 回出荷される（実機）。
- コロボックルが働く日は、飛ぶ直前の好感で決まる。好感は、ふつうに寝た夜ごとに 3 ずつ下がるので、飛ぶ前にキノコを渡して上げておく。
- 種は、まく途中のソフトリセットで 255 回分に増やせる（種グリッチ）。トマトの種でもできる。

## 2. 飛ばした日の畑

- 時計グリッチで飛ばした日は、畑を1日ずつ回す処理（02:4a15）を通る。手伝いのコロボックルが作物に水をやり、作物は育つ。
- 実った作物は、その場で出荷される（00:11ac）。手で出荷箱に入れたときと同じ関数で、その年の出荷数 $B93F と出荷の累計 $BA35 に +1 する。累計は年をまたいで残り、牧場主の判定（出荷 5000）に入る。
- 代金は手伝いの分として貯め、経過時間の画面のあとに所持金へ足す（02:41..）。所持金は 99999G で止まる（00:CheckCurrentMoney）。
- 収穫のあとに戻る状態は、作物で違う。

| 作物 | 収穫のあと | 代金 |
| --- | --- | --- |
| カブ・ジャガイモ・ナス・ラッカセイ・ニンジン | 耕した土 $11（一度きり） | 60・80・60・60・120G |
| トマト | 育つ途中 $5C（実りは $60） | 100G |
| トウモロコシ | 育つ途中 $82（実りは $88） | 120G |
| ブロッコリー | 育つ途中 $EC（実りは $F0） | 120G |

- 季節に合わない作物は、次の季節の1日に耕した土 $11 に戻る（02:4ee1）。夏のトマトは秋1日に消える。
- 夏1日に植えて飛ぶと、トマトの収穫は 6 回（実機。好感 30〜59 のとき。下の 3.）。最初の収穫は飛んだ日 + 8 日、そのあと3日ごとと数えると合う。

## 3. コロボックルが働く日と好感

- 作物を育てるのは、コロボックルが働く日だけ。働く日は、飛ぶ直前の好感 $B9D7 で決まる（02:5002）。

| 好感 | 働く日 | 夏1日に飛んだときの収穫 | 5000 に要るマス |
| --- | --- | --- | --- |
| 90 以上 | 毎日 | 8 回 | 625 |
| 60〜89 | 29 日働いて1日休む | 7 回 | 715 |
| 30〜59 | 6 日働いて1日休む | 6 回 | 834 |
| 30 未満 | 働かない | 0 回 | |

- 収穫の回数は、休む日は育たないとして数えたもの。実機で確かめたのは 30〜59 の 6 回だけ。
- 好感は、ふつうに寝た夜ごとに計算し直す（0f:61d6。毎晩の日付の処理 02:67a1 から呼ぶ）。

| その日にしたこと | 好感 |
| --- | --- |
| 何もしない | −3 |
| 話す | +1 |
| 物を渡す | +3 |

- 話すのと渡すのは別の印（洞窟の処理 TalkToHarvestSprite1 の bit 0 と bit 1）で数える。上限は 99。
- 手伝いで飛ばした日は、この計算を通らない。飛ぶ直前の好感で最後の日まで働く。
- 渡す物は、洞窟でコロボックルの前にあるキノコでよい（マス $26 で拾うと手持ち $30、0e:48d6）。
- 好感 99 から何もしないで寝続けると、33 晩で 0 になる。岩グリッチで 99 にしても、2年目の夏まで寝ると働かなくなる（実機で、出荷・水やりとも 0 だった）。
- 夏1日の好感に効くのは、最後に渡した晩から夏1日までの日数だけ。早く渡しても 99 で止まる。

## 4. 種グリッチ

- 店で買える種は、1種類 99 袋まで（「99 − 今の数」、bank_01b）。
- 種をまく途中でソフトリセットすると、数 0 の袋が残る。次にまくと 0 から1減って 255 回分になる（まく処理 bank_001）。牧草の種を増やす手（[幸福度・家畜・増築](14_仕組み_幸福度・家畜・増築.md) の 5.）と同じ形で、トマトの種でもできる（実機）。
- リセットは最初に1回するだけで、あとは普通にまける。
- 種をまくと、立っているマスを真ん中に 3×3 に落ちる。9マスを1マスずつ見て、耕した土にだけ置く（英語版 GBC の 08:512b〜）。大岩・石・空き地がかかっても、耕した土の分だけ植わる。
- まく1回は約 2 秒（実機）。

## 5. 実機で確かめたこと

| 試したこと | 結果 |
| --- | --- |
| 好感 99 で1年目を飛ばし、2年目に寝て夏まで進めてから、トマトを植えて手伝いを頼む | 出荷・水やりとも 0。寝た夜で好感が落ちていた |
| トマト 36 マスを植え、夏7日ごろに手伝いを頼む | 出荷 216 個（36 マス × 6 回）、所持金が 21600G 増えた |
| 夏1日にトマト 864 マス、好感 30〜59 で手伝いを頼む | 出荷 5184 個（864 マス × 6 回） |
