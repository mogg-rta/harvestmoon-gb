# グリッチ候補と未解決

日本語版 GB と英語版 GBC のコードを比べて探したグリッチの候補と、その今の状態をまとめた資料です。最後に、まだ分かっていないことと、次に縮められそうな所を並べます。番地の書き方は [クリアの条件と評価](10_仕組み_クリアの条件と評価.md) にあります。

## 1. 探し方

- GBC 版は GB 版の作り直しで、卵のグリッチなどが直されている。GBC 版で足された確かめを洗い出せば、GB 版に残る穴の候補になる。セキュリティのパッチの差分を読むのと同じ考え方。
- 日本語版 GB と英語版 GBC の逆アセンブルを処理ごとに区切り、番地・ラベル・バンクを抽象化して比べた。比べる値（cp の値、bit の番号）は残した。
- 処理の数で 87.4% が完全に一致し、RAM の番地もほとんど同じ。評価の判定、耕した面積、時計の処理は完全に一致した。

## 4. 物の拾い直し（A・B・C）

### 仕組み

- GB は物を拾っても、向いているマスの番号（$CB33）・属性（$CB34）・ぶつかっている印（$C90E）を消さない。十字キーを押して実際に1歩動くまで残るので、立ったまま A を押すと、もう無い物を何度でも拾える。
- GBC が塞いだのは2か所だけ。作物を地面に捨てる道（$CB33 を $5c に）と、鶏小屋の卵を置く処理（$CB33 を 0 に）。作物を出荷箱や馬のカバンに入れる道は、GBC でも開いている。
- 1回で2以上数える道、拾う 26 フレームを省く道は無い。1周は拾う 26 と入れる 8 で 34 フレーム（約 0.57 秒）。

### A：卵

- 鶏小屋の A の処理は、$C90E が 0 でも手が空なら卵の分岐へ進む。卵の分岐（04:4e4d）は巣のビットを見ず、$CB33 が $10〜$14 なら卵を持たせる。
- 立ち位置は、向いているマスが $12（水をやった $11 の巣）、投げる先が出荷箱になる所。十字キーに触らずに A だけを押す。
- 下を押し続けると当たり判定が出荷箱に当たり、$CB33 が $02 に変わって拾えなくなる（コードの読み、未確認）。

### B：水なしで卵を回す

- $11 の巣の真上のマスに立てれば、水なしでも回るはず。そのマスを歩けるかは未確認。

### C：作物

- 並びは [自分][実った作物][出荷箱]。拾う → 投げて出荷 → A でまた拾う。十字キーは押さない。
- 畑は時計が進み、17:00 からは数えないので、1日 約 290 個。1日の上限はとうもろこし 218 個（32700G）。
- 出荷 5000 個もお金も卵で足りるので、卵のグリッチを使えるなら得は無い。鶏がいない時期にお金が要るなら、卵の約 2.1 倍の速さで稼げる。
- 英語版 GB の白黒画面で同じことをしている動画がある（Thaao Farms さん、出典）。日本語版で出荷箱の隣のマスを耕せるかは未確認。馬のカバンでも同じことができる見込み。

### そのほか

- 捨てた作物、キノコ、石・柵も拾い直せるが、増えないか出荷箱が無く、使い道は無い。
- 材木・飼料・牛乳は複製できない。種は見ていない。
- 特別な卵（巣4、番号 $25）は、値段の表の外を読んで 1500G になる（GB と GBC で同じで、作りどおりとみる）。出る条件は未確認。

## 5. 状態の確かめ漏れ（1〜4）

### 結論

- 時計を止めたまま外で作業できる道は見つからなかった。時計を止める3つの印は、どれも残しておけない。
  - $CB81（屋内か町）は、扉に入る途中にだけ 1 になる。
  - $CB4E（マップの切り替え中）は、毎フレーム自然に減る。
  - $CB56（文章の窓）が立っていると、牧場の作業の処理（01:43a3）も止まる。
  - 牧場に入るたびに文章の状態が消されるので、小屋から持ち出すこともできない。
- 一番あやしいのは、候補 1 と、牛小屋に入るときの消し漏れの組み合わせ。GBC は両方を直している。

### 候補 1・2：Select の処理（00:3ca0）

- Select を押すと日付などの窓（文章 $00）を出す。押せない条件にマップの切り替えが入っていない。GBC は足している。
- 扉に入って画面が暗くなる約 29 フレーム（約 0.5 秒）の間に Select を押すと、文章を出している途中でマップが切り替わる。
- 切り替わった先で文章の状態が消されるかは、マップによって違う。

| マップ | 文章の状態 |
| --- | --- |
| 牧場、家、山・町、イベントのマップ | 全部消す |
| 牛小屋 | $CB56 だけ 0 にし、$CB52（今の文章）は消さない |
| 鶏小屋、道具小屋 | どちらも消さない |

- 鶏小屋・道具小屋（候補 2）：見えない窓が開いたままで止まり、A で戻る。屋内なので時計はもともと止まっていて、得は無い。
- 牛小屋（候補 1）：動けるのに、文章 $00 を見えない所で出し続ける。文章が終わると、文章の頭に書いてある終わりの処理の番地が、今つながっているバンクで呼ばれる。牧場（バンク1）で始めた文章の終わりの処理が、牛小屋（バンク3）のコードとして呼ばれるおそれがある（推測）。文章 $00 の終わりの処理が空なら何も起きない。GBC は牛小屋の初期化に wTextID＝$FF を足している。

確かめ方

1. 文章 $00 の頭にある終わりの処理の番地を、文章の表（00:3332）から引く。空の処理なら、この候補の見込みはほぼ消える。
2. エミュで $CB4F への書き込みで止め、暗くなり始めたらすぐ Select を押す（1フレームずつ）。
3. 牛小屋に入ったあとの $CB52〜$CB56 を見る。文章の終わり（00:36fc）で止め、終わりの処理の番地と、そのときのバンクを記録する。

### 候補 3・4：待ちの数え方

- 候補 4（01:6acb）：$CB79 は気絶して家に戻るまでの待ち（240 フレーム）。GBC は「文章が出ていれば数を止める」を足した。GB は文章の間も減るので、早く終わるだけ。気絶は寝るより遅いので、RTA の価値は無い。
- 候補 3（0f:67ee）：牧場の扉から入るイベントのマップ（ピクニックか祭りと推測）の終わりの待ち $CC27（240 フレーム）。GB は文章の間も減り、終わりの文章が最大 240 フレームで切られる。時刻は前に進むだけで、巻き戻らない。

## 6. 数値・範囲の確かめ漏れ（6〜10）

### 結論

材木代 4000G を浮かせたり、時間を縮めたりできるグリッチは見つからなかった。お金の上限・下限の直し（CheckCurrentMoney）、幸福度、増築の支払いの確かめは正しい。

### 候補 7：木材がマイナスになると 999 本（00:0fe5）

- 木材（$B938〜$B939）が 1000 以上なら 999 にする処理。GBC は「上の桁が $FF なら 0」を先に足した。飼い葉の同じ処理には GB でも入っていて、木材だけ抜けていた。
- 増える・減る処理は、小屋から取る −2（0 なら取れない）、戻す +2、切り株 +6、大工で買う +50（999 で止める）、増築の支払い −100・−300。確かめと支払いの間にすき間は無い。
- 量がすべて偶数なので、木材が 1 になるのは、一度 999 で止められて奇数になったときだけ。1 のときに取ると −1 になり、999 に戻る。
- 999 にするのに 400 本より多く要るので、RTA の得は無い。
- 確かめ方：$B938＝$01、$B939＝$00 にして小屋で木材を取る。

## 7. そのほかの違い

GB にしか無い処理

- 約 8 割はデータの読み違い。ほかは表示と言語の違い。
- デバッグ画面らしきもの（1f:6b14〜6ff0）がある。年・季節・日と、小屋の道具・種の印を画面に出し、上下で値を変え、B で書き戻す。GBC では消されている。呼び出し元は見つかっておらず、使われない残りとみられる。呼び出せる道があれば大きいので、呼び出し元を ROM 全体で探す価値はある。
- RTC の部品（00:0a2e、00:0a7b）は GBC と一致。GB だけの RTC・タイマーの処理は無い。

確かめ方（上位）

1. 冬29日の夜に 0 時を過ぎてから寝て、冬30日の行事を通す。$B902 と日付、次の朝の日付と体力を見る。
2. えさ箱の前で A を押し、03:4cfb で止めて持ち物（$B8F8〜$B8FB、$CC21）を見る。
3. 1f:6b14 を呼ぶ所（call・jp・表引き）を ROM 全体で探す。
