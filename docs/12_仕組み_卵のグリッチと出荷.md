# 仕組み：卵のグリッチと出荷

牧場主の条件の1つ「出荷 5000」を満たすための卵のグリッチについて、原因、手順、1個の時間、1日に出してよい数、鶏のエサをまとめます。日本語版 GB の逆アセンブルを読んだ結果と、実機で確かめた結果によります。番地の書き方は [クリアの条件と評価](10_仕組み_クリアの条件と評価.md) にあります。

## 1. 結論

- 卵のグリッチは、鶏小屋の $11 の巣の卵の番号 $11 が、畑の「耕した土」の番号と同じなのが原因。ジョウロで水をやると $11 が $12 に変わり、同じマスから卵を何度でも拾える。
- 日本語版の実機でも効く。十字キーに触らず、A だけで「拾う → 出荷箱に入れる」を回す。
- 1個の理論上の最短は 34 フレーム（約 0.57 秒）。1:46:00 の本番（タグ v1）は約 0.7 秒。
- 1日に出してよいのは 468 個まで。469 個以上は所持金が増えずに減る。
- 所持金は 99999G で止まる。

## 2. 原因

### 巣と番号

- 巣の卵は $B9A4 のビットで持つ。鶏小屋に入ると、マップに巣ごとの番号 $10〜$13 を書く（04:5BAE）。bit 0 が $10、bit 1 が $11、bit 2 が $12、bit 3 が $13、bit 4 が $14（特別な卵）。
- 夜の処理（04:6DF1）は、鶏の枠1〜4 の順に bit 0〜3 を立てる。なので $11 は枠2の鶏、つまり2羽目の鶏の巣。画面では左下寄りの巣。
- 何も持たずに A を押すと、向いているマスの番号（$CB33）を見て、$10〜$13 なら巣のビットを消して卵を持たせる（04:4E4D）。

### ジョウロで $11 が $12 に変わる

- 畑では $11 が耕した土、$12 が水をやった土。ジョウロの処理は、場所が畑かどうかを確かめずに、$11 のマスを $12（属性 $00）に変える。
- 鶏小屋では $12 は「$12 の巣の卵」の番号になる。その卵を拾う処理（04:4EC3）は、bit 2 と絵の写しを消すだけで、マップの $12 を消さない。
- なので、水をやった $11 の巣のマスから、卵を何度でも拾える。変わるのは $11 の巣だけで、ほかの巣（$10・$12・$13）は水をやっても変わらない。
- 鶏小屋に入り直すと $11 の巣の卵がまた置かれるので、水は入るたびにかけ直す（推測、未確認）。

### 立ったまま拾い直せる理由

- GB は物を拾っても、向いているマスの番号（$CB33）・属性（$CB34）・ぶつかっている印（$C90E）を消さない。十字キーを押して動くまで残る。
- 鶏小屋の A の処理は、ぶつかっている印が 0 でも、手が空なら卵の分岐へ進む。卵の分岐は巣のビットを見ず、$CB33 が $10〜$14 なら卵を持たせる。
- 十字キーを押すと、当たり判定が出荷箱に当たって $CB33 が変わり、拾えなくなるおそれがある（コードの読み。未確認）。

## 3. 使える版

日本語版・英語版の GB で使える。英語版 GBC では、鶏小屋で水をやってもマスが変わらないように直されていて、使えない。

## 4. 手順

1. 前の日に、鶏小屋のエサ箱へエサを2つ入れて寝る（7. を参照）。翌朝、2羽目の鶏の巣（$11）に卵が出る。
2. ジョウロに水を入れて鶏小屋に入り、$11 の巣のマスに水をやる。
3. 当たり判定の中心が水をやった $11 の巣、投げる先（向いているマスの1つ向こう）が出荷箱になる位置に立つ。水をやったマスの上に立ち、下の出荷箱にぶつかる形とみられる（推測）。
4. 十字キーに触らず、A だけを押して「拾う → 出荷箱に入れる」を回す。

- A は押した瞬間しか効かない。止まっている間に一度離す必要があり、押しっぱなしではためられない。
- 前に鶏がいると、鶏を拾う処理が先に動く。鶏が巣のまわりに来ないようにする。

## 5. 1個の時間

| 動作 | 止まる時間 |
| --- | --- |
| 拾う | 26 フレーム |
| 出荷箱に入れる | 8 フレーム |
| 1周 | 34 フレーム（約 0.57 秒） |

- 卵が出直すまでの待ちはコードに無い。止まる時間が終われば、すぐ拾える。
- 物の種類で、拾う・入れるフレーム数は変わらない。持ち上げずに出荷する手、1回で2以上数える手は見つからなかった。

| 走り | 1個 | 5000 個 |
| --- | --- | --- |
| 理論上の最短 | 34 フレーム（約 0.57 秒） | 約 47 分 |
| 1:46:00 の本番 | 約 0.7 秒（約 42 フレーム） | 約 1 時間（卵の区間 1:01:25 で 5040 個） |

## 6. 出荷の数え方と所持金

### 数える処理

- 出荷を数える処理は 00:1C81。時刻が 6:00〜16:59 のときだけ数える。
- 鶏小屋の中は時計が止まるので、16:59 より前に入れば何個でも数えられる。
- 数えるたびに $B93F（年ごと）と $BA35（累計）を +1 し、値段をその日の出荷額 $B93D（2バイト）に足す。卵は 70G。

### 所持金への入り方

- 17:00 に牧場にいると、その日の出荷額 $B93D を預かり $B8FC に移し、$B93D を 0 にする。
- 夜（寝たとき）に、所持金へ $B8FC と $B93D を1回ずつ足し、そのあと上限・下限を直す。
- 足す処理（00:0A14）は、2バイトの額の一番上のビットが立っていると負の数として扱う。上限・下限の直しは、2回足したあとに1回だけ。
- 所持金は 99999G で止まり、マイナスなら 0G になる。

### 1日 468 個まで

| その日の卵 | 1回分の額 | 所持金 |
| --- | --- | --- |
| 468 個まで | 70×個数（468 個で 32760G） | 増える |
| 469〜714 個 | 70×個数 − 65536 | 減る（469 個で −32706G、714 個で −15556G） |
| 715 個以上 | その日の出荷額が 50000 で止まり、50000 − 65536 ＝ −15536G | 15536G 減る（0G より下にはならない） |

- 469 個（32830G）から、額が符号付き 16 ビットの正の上限 32767 を超えて負になる。
- 出荷数そのものは、何個でも数に入る。
- 469〜714 個の日の減り方は未確認。

## 7. 鶏のエサと卵

### 卵が出る条件

- 鶏は4枠（$B9A7・$B9B3・$B9BF・$B9CB）。買った鶏は大人で、空腹でない状態で入る。
- エサ箱4つに入れたエサは $B9A6 に持ち、6:00 以降に「食べる分」へ写す。
- 夜（04:6CF6）、食べる分のエサ1つにつき、大人の鶏を枠の順に1羽ずつ食べさせる。食べられなかった鶏は空腹の印が立つ。
- そのあと巣の卵をいったん全部消し、空腹でない大人の巣にだけ卵を置く。エサ箱は空になる。
- まとめると、前の日の 6:00 以降にエサ箱へエサを入れて夜を越すと、翌朝その鶏の巣に卵が出る。
- グリッチに要るのは $11 の巣（2羽目）の卵だけ。エサは枠の順に食べるので、2羽目に食べさせるには1晩に2つ入れる。巣の卵は毎晩消えるので、グリッチをする日の前の日に毎回入れる。

### 空腹

- エサを食べられなかった鶏は空腹になり、卵を産まなくなる。空腹で死ぬことはない。
- 空腹は、3晩続けて食べると消える。

### エサの数

- エサの数は $B93A・$B93B（最大 999）。小屋のエサの出口で1つ取ると1減る。育った牧草をカマで刈ると1増える。
- 店のエサは1袋 500G。

### 鶏を売って買い直す

- 2羽目の鶏を売って買い直すと、次の日からグリッチに使う位置（$11 の巣）に卵を産む（実機）。
- 買い直した鶏は空腹でないので、その晩にエサを入れれば翌朝に卵がある。3晩食べさせて空腹を戻すより速い。
- 売値と買値はどちらも 500G で、お金は変わらない。ただし鶏を売ると幸福度 −20（[幸福度・家畜・増築](14_仕組み_幸福度・家畜・増築.md)）。
