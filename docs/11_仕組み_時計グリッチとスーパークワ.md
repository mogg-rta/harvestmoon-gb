# 仕組み：時計グリッチとスーパークワ

日本語版のスーパークワがカートリッジの時計（RTC）を要る仕組みと、それを一瞬で満たす時計グリッチ（時計の引き算を負にする手）をまとめた資料です。この走りの中心の技で、1年目の残りを飛ばすこと、2年目をスーパークワで耕すこと、2年目の夏から冬にかけてトマトを出荷させること、3年目の冬の終わりを飛ばすことは、どれもこの技によります。番地の書き方は [クリアの条件と評価](10_仕組み_クリアの条件と評価.md) の 1. にあります。

## 1. 結論

- 日本語版 GB のカートリッジは MBC3＋時計＋電池。コロボックルに預けたクワは、手伝いの経過時間が合計 24 時間になるまで返らない。経過時間は実時間で数える（実時間 15 分でゲームの1時間、速い設定で 7.5 分）ので、普通に待つと実時間で6時間かかる。
- 時計グリッチは、タイマーの窓で手伝いに YES と答えるのと同じフレームにソフトリセットをかけ、経過時間の引き算を負にする手。負になると上限の 2880 時間が入り、年末で止める処理でその年の冬30日 6:00 まで飛ぶ。
- 飛んだときに、スーパークワ（24 時間以上）とスーパーカマ（12 時間以上）を同時に受け取れる（実機で確認）。
- 入力は「B・セレクト・スタートを押さえたまま A を押す」だけで、フレーム単位の正確さは要らない。ゲームボーイプレーヤーと GC コントローラーで成功している。
- 使う前に1分待つ必要がある（4. の「1分」の目安）。

## 2. スーパークワの仕組み（日本語版 GB）

### 預ける

- コロボックルを洞窟の岩から助けたあと、話しかけるとカマとクワを預ける話が出る。条件はコロボックルの好感（$B9D7）で、カマは 30 以上、クワは 50 以上。
- 1回話すごとに会話が1段進む。同じ日に続けて話しかけると、あいさつ（力の木の実をもらう）→ カマの話 → クワの話の3段とも進む（実機で確認）。
- 岩を割った日はそのまま話しかけられない。次の日に進む必要がある（実機で確認）。
- 預けると、棚からクワが外れ（$B8A4＝0）、受け取りの時間 $BA39 が 0 になる。

### 好感

- 岩をハンマーで1回たたくごとに +10（上限 99）。助けたこと自体では増えない。
- 夜を越すと、物を渡していなければ −3、話した日は +1、物を渡した日は +3。
- 岩をたたく手（岩グリッチ）と幸福度の増え方は [幸福度・家畜・増築](14_仕組み_幸福度・家畜・増築.md) にある。

### 返る

- 経過時間を $BA39 に足し、24 以上になると棚にスーパークワが出る（$B8A8＝1）。何回かに分けても、合計 24 時間でよい。棚に出ることは実機で確認した。
- スーパーカマは 12 時間以上で返る。
- この処理は、経過時間の画面（つづきから始めたときに出る画面、マップ $28）の中だけで走る。経過時間の画面に入るのは、手伝い中（$B90A＝1）につづきから始めたときだけ。
- 手伝いを頼まずに遊ぶ・寝る・電源を切るだけでは、経過時間は足されず、クワは返らない。
- エミュの時計を進めても受け取れるとみられるが（未確認）、板のルール（エミュの設定は初期のまま）に反するとみられ、RTA では使えない。

## 3. 手伝いと経過時間の仕組み

### 手伝いを頼む

- 手伝いは、マップの上で開く窓（犬笛・タイマー・馬笛・メモ）の「タイマー」から頼む。条件は、洞窟でコロボックルと初めてやりとりしたこと（$B909）だけ。
- YES と答えると、手伝いの文を出し、$B90A＝1 にし、印 $BA44〜$BA46 を書き、RTC を 0 に戻す（00:0a2e）。時計の基準 $B886〜$B889 は書き直さない。
- NO と答えると $B90A＝0 になる。$B90A を 0 に戻すのはこのときだけ。

### 時計の基準

- 経過時間は「今の RTC − 時計の基準（$B886〜$B889）」で出す。
- 遊ぶマップ（牧場・家・洞窟など）は、毎フレームの頭で基準を書き直す（00:0ae9）。書く値は前のフレームの終わりに読んだ RTC の写し。タイトルとつづきの選びの画面は基準を書かない。

### RTC が 0 に戻るとき

1. New Game
2. タイマーで YES
3. 経過時間の画面

## 4. 時計グリッチ

### 原理

- 1フレームの中の順番は次のとおり。
  1. ボタンを読む（VBlank の頭）。$FF8A が押しっぱなしのボタン、$FF8B がそのフレームで新しく押したボタン。
  2. マップの処理。頭で基準を書く（00:0ae9）。
  3. 同じマップの処理の中で文章の処理（00:362c）が走る。YES/NO の選び（00:3892）は、A を新しく押したフレームに、その場で文章の終わりの処理を呼ぶ。ここで YES なら RTC が 0 に戻る。
  4. VBlank に戻り、RTC を読んで写しを取る（00:0a7b）。ここで写しは 0 になる。
  5. ソフトリセットの判定。$FF8A の下の4ビット（A・B・セレクト・スタート）がすべて立っていればリセットする。押しっぱなしで判定する。
- 普通に YES と答えると、次のフレームの頭で基準も 0 近くに書き直される。電源を切っても1フレームも間に合わない。
- YES を A で決めるのと同じフレームでソフトリセットがかかると、RTC は 0、基準は YES の直前の値のまま、で止まる。ソフトリセットは WRAM と HRAM だけを消し、基準のある SRAM は消さない。$B90A も 1 のまま残る。
- つづきから始めると経過時間の画面に入り、「今の RTC（ほぼ 0）− 基準（YES の直前の値）」が負になって、上限の 2880 時間が入る。

### ほかのボタンが邪魔をしないか

- 押しっぱなしの B・セレクト・スタートは、YES/NO の選びを邪魔しない。YES/NO の選びが見るのは、新しく押した A と十字キーの左右だけ。
- セレクトは、質問の文が出てから押さえる。メニューが開いている間に押すと、メニューの処理に取られる。

### 入力

1. 最後のソフトリセットから1分以上たってから、牧場か家でタイマーの窓を開き、「手伝ってほしい？」へ進む。
2. 2ページ目（YES/NO）の文字が出ている途中に B を押さえ、セレクトとスタートも押さえる。カーソルは YES のまま、十字キーに触らない。
3. A を押す。同じフレームで YES が決まり、ソフトリセットがかかる。
4. すぐにつづきから始める。経過時間の画面に冬30日 6:00 が出れば成功。

- ゲームボーイプレーヤーと GC コントローラーでは、B・スタート・Y（GB のセレクト）を押さえたまま A を押して成功した（実機で確認）。
- B は文字が出きったあとに新しく押すと取り消しになるので、文字が出ている途中に押さえる。
- タイトルで待たない。タイトルで待ってデモに入ると、デモのマップが基準を書き直すおそれがある（未確認）。

### 失敗の3種類

| 見た目 | 何が起きたか | 害 | 立て直し |
| --- | --- | --- | --- |
| 経過時間の画面が出ず、家から始まる（先にリセット） | A より先に4つがそろい、YES の前にリセットされた | 何も変わらない | ソフトリセットがかかったので、実時間で 70 秒ほど待ってから、もう一度タイマーの窓から |
| 経過時間の画面が出るが、経過がほぼ 0 時間（手伝いが始まった） | A が先に通って YES だけが入り、手伝いが始まって RTC が 0 に戻った | 小さい | つづきから始めて、実時間で 70 秒ほど待ってからやり直す |
| リセットのあと、つづきからを選ぶと白い画面のまま進まない | 分からない（未確認）。1回だけ起きた。うまくいった回と比べて、録画の上で見える違いは、▶はい が出てから A までの間（0.33 秒と 0.10 秒）だけ | セーブは壊れない | 電源を入れ直してつづきから始めると、ふつうに続く。白い画面が数秒続いたら待たない |

### 「1分」の目安

- コードの読みでは、成功には「YES の直前に、RTC が最後に 0 に戻ってから1分以上たっている」ことが要る。基準の分が今の分より大きいときだけ負になるから。
- 1分たっていないと、押し方が正しくても差が負にならず、見た目は「手伝いが始まった」失敗と同じになる。待ち時間の不足と押す順番の失敗は、見た目では分けられない。
- 実機では、RTC が 0 に戻ってから（New Game、YES、経過時間の画面のどれか）60 秒たっていれば確実に成功した。
- 走りでは「最後のソフトリセット（岩グリッチ）から1分」を目安にしている。ソフトリセットは RTC を 0 に戻す3つに入っていないので、この目安とコードの読みがどう合うかは未確認。

### 飛ぶ量

- 負になったときに入るのは上限の 2880 時間（丸1年）。
- 年が変わる分は「その年の冬30日 6:00」で止め、経過時間もその分削る（02:43d5）。なので、どの日に使っても冬30日 6:00 に着く。
- 削ったあとの量で、スーパークワ（24 時間以上）、スーパーカマ（12 時間以上）、体力の全回復（24 時間以上）を判定する。スーパークワとスーパーカマは実機で確認した。体力の全回復は未確認。
- 削ったあとの量は、コロボックルの時間 $BA10 にも足す。

| 使った日時 | 経過時間 | 確かさ |
| --- | --- | --- |
| 春1日 7:00 | 2855 時間（119 日 − 1 時間） | 実機で確認 |
| 春1日 8:00 | 2854 時間 | 実機で確認 |
| 夏10日 10:00 | 1916 時間 | コードからの計算 |

- 年に1回まで。年末で止めたあとにもう一度使っても、経過 0 時間で年は越せない。
- その年の冬30日 6:00 以降に使うと、年末で止める処理で削られて何も飛ばない。

### 経過時間の画面で起きること

- 飛ばした日の中で、牧草は育ち、作物は育って収穫・出荷される。出荷は牧場主の判定（出荷 5000）に入り、代金は所持金に入る（[作物と手伝いの出荷](17_仕組み_作物と手伝いの出荷.md)）。
- コロボックルが働く日数は、飛ぶ直前の好感で決まる。90 以上で毎日、60 以上で 29 日働いて1日休む、30 以上で 6 日働いて1日休む、30 未満で働かない。好感が低いと、画面の「おてつだいのけっか」の出荷数・水やりの日・エサの日はどれも 0 になる（実機で確認）。
- 増築も飛ばしの中で進む。2回目の増築は、頼んで支払ったあとに飛ばしても完成し、ウルトラデラックス木の家になった（実機で確認）。処理の中身は未確認。飛ばしの中で増築が終わったときの幸福度 +10 も未確認（[幸福度・家畜・増築](14_仕組み_幸福度・家畜・増築.md)）。
- 経過時間の画面のあとは評価の場面へ進む。家の処理（02:50f5）も、その年の評価が済んでいない（$BA43 が 2 でない）と評価へ進める。1年目・2年目に使ったときは、評価の場面のあと次の年の春1日から始まった（実機で確認）。
- 評価の場面の終わりに $BA10 が 0 に戻る。牧場主にならない年に使う限り、次の年のコロボックルの時間の条件は壊れない。牧場主になる年は、飛ぶ時間を 240 時間以内にする（[クリアの条件と評価](10_仕組み_クリアの条件と評価.md) の 4.）。

### 使ったあとに残ること

- 手伝い中の印 $B90A は 1 のまま残る（0 に戻すのはタイマーで NO を選んだときだけ）。以後はソフトリセットのたびに経過時間の画面を通り、A を1回押す手間が増える。
- リセットからつづきまでの実時間も経過時間に入るが、実時間 15 分でゲームの1時間なので、すぐ続ければ 0 時間。
