# 仕組み：日の進みと寝ること

牧場物語GB（日本語版）の時計の進み方、寝る1晩の処理と長さ、体力の回復、セーブとリセット、乱数と天気をまとめた資料です。番地の書き方は [クリアの条件と評価](10_仕組み_クリアの条件と評価.md) の 1. にあります。

## 1. 結論

- 時計は1時間 900 フレーム、実時間で約 15 秒。6:00 から 24:00 までは約 4.5 分。
- 屋内・町・文字の窓の間は時計が止まる。家・小屋・店の中の作業は時間を使わない。
- 町に入ると必ず1時間進む。
- 寝る1晩は、初めの家で約 4.21 秒。最初の約 50 回の朝は食事の場面が入り、約 5.8 秒になる。
- 22 時台までに寝れば体力は全回復。それより遅いと、寝た時刻に応じて回復が減る。
- セーブという処理は無い。時刻・所持金・畑などは電池つきの SRAM にその場で書かれ、リセットしても戻らない。リセットで戻るのは、手に持っている物や乱数など WRAM・HRAM の中身だけ。
- リセットすると天気の乱数が 0 に戻る。翌日の天気、1年目の地震の日、毎年の台風の日はこの乱数で決まる。

## 2. 時計

- 1時間は 900 フレーム（約 15 秒）。時計の処理は 32 フレームのうち 16 フレームでしか呼ばれない。
- 24 時で日が進み、30 日で季節が進む。
- 出荷箱に入れる処理の一つは、6:00〜16:59 の間だけ数える。卵の出荷の話は [卵のグリッチと出荷](12_仕組み_卵のグリッチと出荷.md)。

### 時計が止まる所

| 止まるとき | フラグ |
| --- | --- |
| 屋内か町にいるとき | $CB81 |
| マップを移っている間 | $CB4E |
| 文字の窓が出ている間 | $CB56 |
| 一時停止の間 | |

- 時計が止まったまま作業できる所：家、牛小屋、鶏小屋、道具小屋、町の店、会話の窓。
- 鶏小屋の中も止まるので、卵のグリッチは時計が止まったままできる。1日に卵を 3400 個以上出せる（実機で確認）。

### 町に入ると1時間進む

- 町に入ると必ず1時間進む（実機で確認）。

## 3. 寝ること

### 寝る処理

1. ベッドで A を押し、YES。80 フレーム（1.33 秒）かけてベッドに入る。
2. 家のマップを読み直し、新しい日の処理をする。
   - 寝た時刻が 6 時以降なら、日を1進めて 6:00 にする。0〜5 時に寝たときは、0 時で日が進んでいるので 6:00 にするだけ。
   - 体力を回復する（下の「寝た時刻と体力の回復」）。
   - 出荷の代金を所持金に足す。
   - 天気を移し、朝のイベントを決め、次の日の天気を引く。
   - 畑の全マス（3136 マス）を処理する。
3. 朝の食事（下の「朝の食事」）。

- 文字は1フレームに1文字出る。ボタンで速くはならない。A は文が出きったときだけ効く。

### 1晩の長さ

| 家 | 1晩（食事なし） | 確かさ |
| --- | --- | --- |
| 初めの家 | 約 4.21 秒 | 実機の録画で測った（30 コマ／秒） |
| デラックス木の家（1段階目） | 約 4.13 秒 | 同上。差の約 0.1 秒は、ベッドまで1マス近い分（6 フレーム）と合う |

- 削れない所は、ベッドに入る動きの 80 フレーム。残りはフェード、畑の処理、歩く時間。それぞれの長さは測っていない。

### 朝の食事

- New Game で、家の食べ物が5種類 10 個ずつ、合わせて 50 個入る（$B8C5・$B8C6・$B8C7・$B8CA・$B8CB に 10、$B8CC は 0）。
- ベッドで寝て起きた朝に、残っている物から1つ選んで食べる。種類は乱数 $FF9C で選ぶ（02:5dee）。この数を減らすのは朝の食事だけで、売る・捨てる処理は無い。
- なので、最初の約 50 回の朝は食べる場面が入り、1晩 約 5.8 秒になる（食べない朝は約 4.2 秒）。避ける手は無い。

### 寝た時刻と体力の回復

寝た時刻ごとの回復の量は [耕作と片付け](13_仕組み_耕作と片付け.md) の 6. にある。22 時台までに寝れば全回復する。

- 6:00 から 23:00 までは約 4 分 15 秒。家・納屋の中や文字の間は時計が止まる。

### 寝る以外の日の進め方

| 方法 | 結果 |
| --- | --- |
| 牧場で 5:14 まで起きている | 気絶して家に戻る。体力は回復しない（$B900）。6:00 から待つと約 5.8 分かかり、寝るより大幅に遅い |
| 外で 24 時を越える | 日付が進むだけで、作物・天気・出荷の処理は動かない。得は無い |
| コロボックルの手伝い（RTC） | 普通に使うと実時間 15 分（速い設定で 7.5 分）でゲームの1時間で、使えない。時計グリッチなら冬30日まで飛べる（[時計グリッチとスーパークワ](11_仕組み_時計グリッチとスーパークワ.md)） |

## 4. セーブとリセット

### セーブの仕組み

- セーブという処理は無い。時刻・所持金・畑・家畜などは、電池つきの SRAM に直接書かれる。
- ソフトリセット（A＋B＋セレクト＋スタート）は WRAM と HRAM だけを消し、SRAM は消さない。
- リセットのあとつづきから始めると、時刻はそのままで家に戻る。新しい日の処理は走らない。
- ソフトリセットから家の入口に戻るまで約 8 秒（実機で測った）。
- 時計グリッチを一度使うと、以後はつづきのたびに経過時間の画面を通り、A を1回押す手間が増える（[時計グリッチとスーパークワ](11_仕組み_時計グリッチとスーパークワ.md) の 4.）。

### リセットで戻るもの・残るもの

| 戻る | 残る |
| --- | --- |
| 手に持っている物、まいている途中の種の数 | 時刻、日付 |
| 天気の乱数 $FF9D（0 から始まる） | 所持金、その日の出荷 |
| | 耕したマス（実機で確認） |
| | 幸福度、コロボックルの好感（岩をたたいた分） |
| | 時計の基準 $B886〜$B889、手伝い中の印 $B90A |

- 時間は巻き戻らない。リセットは「やり直し」ではなく、時刻そのままで家に戻る手として使う。
- 地震の日の岩グリッチは、岩をたたいた時点で入る幸福度と好感が SRAM に残ることを使う（[幸福度・家畜・増築](14_仕組み_幸福度・家畜・増築.md)）。リセットしてもその日の出荷とお金は消えない（実機で確認）。
- 牧草の種は、まいている途中でリセットすると増える（実機で確認。255 回分になる。[幸福度・家畜・増築](14_仕組み_幸福度・家畜・増築.md)）。
- 手伝いを使っていなければ、リセットでコロボックルの時間は増えない。経過時間を足すのは、手伝い中（$B90A が 1）につづきから始めたときだけ。

## 5. 日付で起きるイベント

朝のイベントは1日に1つ。起きると場面が流れ、その間は時計が止まる。

| 番号 | 起きる日 | 中身（推測を含む） |
| --- | --- | --- |
| $13 | 2年目以降の春1日 | 評価の続き（推測） |
| $03 | 春の最後の週の土曜 | ピクニックの誘い（推測） |
| $04 | 誘いを受けた日 | ピクニック（推測） |
| $05 | 毎年の秋10日 | 収穫祭（推測） |
| $11 | 毎年の冬30日 | 評価（[クリアの条件と評価](10_仕組み_クリアの条件と評価.md)） |

- 状態で起きるもの：$0a（耕地 128 マス以上でスプリンクラーを持っていない）、$0b・$12（増築）、ほか。

## 6. 乱数と天気

### 乱数

| 値 | 進み方 | 使われる所 |
| --- | --- | --- |
| $FF9D | 呼ばれたときだけ表を1つたどる（周期 202）。フレームによらない | 天気、地震の日、台風の日、台風でマスが戻る判定、犬・猫の動き |
| $FF9C | 毎フレーム X ＝ 5X ＋ 17 | 牛・鶏の病気、釣り、牛を買うときの値、朝の食事の種類 |
| $C0A8 | 毎フレーム1増える | $FF9C を引くときに足す |

### 天気

- 翌日の天気は、季節ごとの 32 通りの表から $FF9D で選ぶ。日本語版は春の雨 3/32、夏の雨 5/32、秋の雨 3/32、冬の雪 11/32。
- リセットで $FF9D は 0 から始まる（0 → $27 → $54 → $12 → …）。リセットのあと何回目に引くかで天気が決まる。

| リセット後の何回目 | 天気 |
| --- | --- |
| 1回目 | どの季節も晴れ |
| 2回目 | 夏は雨 |
| 5回目 | 春・秋は雨 |
| 6回目・10回目 | 冬は雪 |

- 犬・猫の動きが途中で $FF9D を進めないことが前提（未確認）。
- 必ず晴れる日：夏20日、秋10日、1年目の冬20日、ピクニックの日、台風の次の日。

### 地震の日

- 1年目の夏の決まった日の 6:00 に家にいると起きる。3 秒揺れて、洞窟の入口に岩が出る。避けられない。
- 日は1年目の春28日の夜に $FF9D で決まる。夏2〜10日のどれかになる。
- 地震の日に岩をたたいてコロボックルを助けることが、好感・幸福度・時計グリッチの入口になる（[時計グリッチとスーパークワ](11_仕組み_時計グリッチとスーパークワ.md) の 2.）。

### 台風

- 夏の決まった日に来る。日は毎年の春29日の夜に $FF9D で決まる。
- その朝、湿った耕し地が 1/64 ずつ空き地に戻る（[耕作と片付け](13_仕組み_耕作と片付け.md)）。次の日は必ず晴れ。
