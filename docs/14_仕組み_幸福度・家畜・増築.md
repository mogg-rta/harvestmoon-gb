# 仕組み：幸福度・家畜・増築

牧場主の条件のうち、幸福度、力の木の実、家畜、増築に関わる仕組みをまとめます。日本語版 GB の逆アセンブルを読んだ結果と、実機で確かめた結果によります。条件そのもの（幸福度 250、力の木の実6個など）は [クリアの条件と評価](10_仕組み_クリアの条件と評価.md) に、番地の書き方も同じ資料にあります。

## 1. 結論

- 幸福度は 0〜255 で止まり、あふれない。評価には 250 以上が要る。
- 岩グリッチは、地震の日の岩をハンマーでたたき、割れる前にソフトリセットするくり返し。1回で幸福度 +10、コロボックルの好感 +10。
- 力の木の実は3か所でしか増えない。1年目に取れるのは最大5個。
- 鶏は 500G・牧草 36 マス、牛は 5000G・牧草 54 マスで買える。牧草は種をまいた瞬間から数に入る。
- 牧草の種は、まく途中のソフトリセットで減らなくなる。お金を使わずに牧草をまける。
- 増築は支払った日から4日目の朝に完成する。1回目が終わると、普通のハンマーはスーパーハンマーに置き換わる。

## 2. 幸福度（$B8F2）

増減はすべて 00:0FB9 を通ります。符号付きで足し、上は 255、下は 0 で止まります。初期値は 0 です。

### 何度でも増えるもの

| 行動 | 点 |
| --- | --- |
| 牛を買う | +20 |
| 鶏（評価のとき1羽ごと） | +10 |
| 耕地（評価のとき 64 マスごと） | +1 |
| 子牛が生まれる | +30 |
| 教会の占い（1日1回） | 3/16 で +10、3/16 で −10 |
| 牧場で何もせず 511 フレーム立つ（晴れの日） | 3/16 で +1（平均 約 45 秒で1点） |
| 朝 6:00:00 ちょうどに外へ出る | 2/16 で +1 |

- 鶏と耕地の分は、評価のたびに前の年の分を引いてから足し直す。年をまたいでたまらない。

### 1回きりの出来事

| 出来事 | 点 |
| --- | --- |
| 1回目の増築が終わる | +10（2回目は入らない） |
| 地震の日の岩をハンマーでたたく | 1回 +10。割れる前にリセットすればくり返せる（3.） |
| 小鳥を探すのを引き受ける | +10（「はい」と答えたときに入る。見つけなくてよい） |
| 風見鶏を見つける | +10 |
| ニーナを見つける | +10（引き受けただけでは入らない） |
| 新しいジュースを飲む | +10（断ると −10） |
| 泊めてほしい人に「はい」 | +10（「いいえ」で −10） |
| 卵の子にお釣りを返す | +20（返さないと −20） |

- 減るもの：牛を売る −40、鶏を売る −20、牛が病気 −10、牛の愛情が 100 を下回る −10、牛が死ぬ −100。
- 馬を預かる出来事、ピクニック、収穫祭のクッキーでは動かないとみる。

## 3. 岩グリッチとコロボックル

### 岩グリッチ

- 地震の日（1年目の夏2〜10日のどれか）に、洞窟でコロボックルが岩に閉じ込められる。
- 岩をハンマーで1回たたくと、幸福度 +10、コロボックルの好感（$B9D7）+10。好感の上限は 99。
- たたくと印（$BA0E）が立ち、たたく動きのあとに岩が割れて助けた扱いになる。助けたこと自体では幸福度も好感も増えない。
- 割れる前にソフトリセットすると、+10 だけ残る。洞窟に入り直すと印が消えるので、くり返せる。
- リセットしても、その日の出荷とお金は消えない（実機）。

### コロボックルの好感

| 変わり方 | 量 |
| --- | --- |
| 話す（毎晩の分） | +1 |
| 手に持つ物を渡す（毎晩の分） | +3 |
| 渡さない日（毎晩の分） | −3 |
| 地震の日の岩をハンマーでたたく | +10 |
| ハンマー以外の道具をコロボックルに5回当てる | −10 |
| 岩を助けないまま日がたつ | −10 |

- コロボックルとの会話と、預けたクワをスーパークワとして受け取る手は [時計グリッチとスーパークワ](11_仕組み_時計グリッチとスーパークワ.md) にあります。

## 4. 力の木の実（$B904）

### 増える所

1. 牧場の隠れたマス（番号 $0C）をクワで耕す。もとの牧場に4か所、広げる土地に2か所。
2. コロボックルから1回だけもらう。好感 10 以上で話しかける。
3. 洞窟の岩をツルハシでたたく。ツルハシは評価のごほうびなので、最短の流れでは取れない。

- 1年目に取れるのは最大5個（もとの牧場の4か所とコロボックル）。

### 効果

- 1個で最大体力 +10。10 個で止まる。
- 走りでの効き目は、エンディングの条件（6個）と、1日に振れる回数が増えること（耕作の日数が減る）の2つ。耕作の体力は [耕作と片付け](13_仕組み_耕作と片付け.md) にあります。

## 5. 家畜

### 値段と条件

| | 牛 | 鶏 |
| --- | --- | --- |
| 値段 | 5000G | 500G（売っても 500G） |
| 買う条件（牧草のマス） | 54 以上 | 36 以上 |

- 牧草は、種をまいた瞬間から数に入る（実機）。牧草も耕地として数に入る。
- 家畜屋に休みの曜日はなく、毎日 8 時に開く（実機）。
- 評価は枠が空でなければ数える。子牛、ヒヨコ、病気の牛も1頭・1羽。

### エサを切らしたとき・病気・死ぬ条件

- 鶏：エサが無い夜は空腹になり、卵を産まなくなるだけ。死なない（[卵のグリッチと出荷](12_仕組み_卵のグリッチと出荷.md) の 7.）。
- 牛：飼料が無い夜は愛情 −8。これだけでは病気にも死にもならない。
- 牛が病気になるのは、雨や雪の日に外に出ている牛（推測）だけ。愛情 −10 のうえ 1/16 で病気になり、幸福度 −10。
- 病気のまま7晩たつと死に、幸福度 −100。薬で治すと数え直しになる。

### 牧草の種を増やす手

- 牧草の種をまいている途中にソフトリセットすると、種が減らない（実機）。つづきから始めて、牧草を 10 回以上まけた。
- 種の残りの回数（$B8DA）は、まいたときに1減り、0 になると袋を手から消す合図（$CB8F）を立てる。合図が働く前のリセットで合図だけが消え、回数 0 の袋が手に残る。次にまくと 0 − 1 で 255 回分になる、とみる（推測。255 回かは未確認）。

## 6. 増築

### 日数と費用

| | 1回目 | 2回目 |
| --- | --- | --- |
| 費用 | 2500G | 5000G |
| 材木 | 100 本 | 300 本 |
| 家 | デラックス木の家 | ウルトラデラックス木の家 |

- 頼む → その晩、出来事がなければ翌朝に大工が見積もりに来る → 「はい」で支払う → 支払った晩から毎晩進み、4日目の朝に完成する。出来事のある晩は進まない。
- 2回目は、1回目が終わるまで頼めない。
- 時計グリッチの飛ばしの中でも完成する（実機。2回目で確かめた）。

### 材木

- 大工で1回 500G で 50 本。999 本まで。
- 切り株をオノで割ると +6 本。

### ハンマーがスーパーハンマーに置き換わる

- 1回目の増築が終わると、手に持っている普通のハンマーは消え、スーパーハンマーに置き換わる。両方は持てない。
- 普通のハンマーは1回 体力 2、スーパーハンマーは1回 体力 3。体力は叩く物を見る前に減るので、小さい石でも空振りでも同じ。
- 小さい石はどちらも1回で割れる。スーパーハンマーで得をするのは大岩だけ。

### 大岩の割り方

- スーパーハンマーなら1回で割れる。
- 普通のハンマーなら、動かずに6回続けて叩くと割れる（実機）。割れるまでの数（$C611）は、歩くと 5 に戻り、叩くたびに1減り、0 で叩くと割れる。

## 7. 所持金

- 所持金は $B8EF〜$B8F1 の3バイト。99999G で止まり、マイナスなら 0G になる。
- 出荷でお金が入る仕組みと、1日 468 個の上限は [卵のグリッチと出荷](12_仕組み_卵のグリッチと出荷.md) の 6.。
