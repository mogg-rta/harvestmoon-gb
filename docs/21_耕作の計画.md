# 耕作の計画

2年目の春1日から春10日まで、片付け3日と耕す7日で、耕した広さ 1600 を超える計画です。線の引き方は何通りもあるので、ここでは何を大事にして決めたかと、実際に決めたやり方をまとめます。仕組み（クワの1振り、体力、畑の広さ、片付け）は [耕作と片付け](13_仕組み_耕作と片付け.md)、通しのルートは [ルート](20_ルート.md) にあります。

畑の地図は、チャート https://mogg-rta.github.io/harvestmoon-gb/ の2年目の各日で見られます。日ごとの線、お金や物が出る目印、片付ける物と通り道を地図に重ねて表示します。

## 1. 方針

1. 最適解は求めない。シンプルで再現性の高い線にする。
2. 同じ型を繰り返して、覚える手を少なくする。型は、縦の1本の線を往復しながら両側へ振ること。行きは1行ごとに片側へ、帰りは反対側へ振り、帰りは6行ごとに進む向きにも振って線の上も耕す。1往復で幅 13 マスの帯が耕せる。
3. 1600 に余りを持たせる。今の線で、評価の見込みは 1634（余り 34）。3年目の台風で減る分（最大 16 マス）が入っても足りる。
4. 振りの効率は詰めない。草・石で6マス目の手前で止まる振りがあってもよい。1マスしか耕せない振りは飛ばす。
5. 草・石・切り株は、耕す日より前の別の日に片付ける。耕す日は振るだけにする。
6. 片付けは、見える範囲の中で次の動きが決まる形にする。画面に見えるのは主人公のまわり左右・上下 4〜5 マスほどで、遠くの物を目印にして回ると迷う。
7. 線は手で組む。耕すマスの数、振りの回数、体力が足りるかは、組んだ線を確かめるために数えるだけで、計算でいちばんよい線を探すことはしない。

## 2. 座標

座標は (x, y) で、マップの左上が (0, 0)。x は右（東）へ、y は下（南）へ増える。「y 24→44」は、y 24 から y 44 へ向かって歩くこと。

## 3. 片付けの3日

1日1種類の作業にしています。片付けに要る体力は計 341（カマ、切り株、石）で、1日の体力 150 に収まらないので3日に分けます。日を増やしても寝る晩は増えません。

| 日 | 中身 | 通り道 |
| --- | --- | --- |
| 片付け1（春1日） | 北の草と切り株。納屋でスーパーカマとスーパーオノを取り出す | カマ：家 → 杭を抜いた所 (13,11) → 北の畑の西の端 → y 6 を東の端まで → x 45 を南へ y 14 まで → y 14 を西へ x 35 まで → x 35 を南へ y 20 まで。素手：来た道を逆にたどって家へ。オノ：南の畑を西から東へ → 右下 → 右の畑の西の帯を北へ → 北の畑を東から西へ（切り株 19 個） |
| 片付け2（春2日） | 南の草 | カマ：家 → 南の出入り口 (9,30) → 西の端 → y 33 を東へ x 47 まで → (62,25) へ → y 25 を西へ x 36 まで → (62,30) へ → x 62 を南へ y 41 まで → y 41 を西の端まで。素手：来た道を逆にたどって家へ |
| 片付け3（春3日） | 石。納屋でスーパーカマをハンマーに、スーパーオノをスーパークワに持ち替える | ハンマー：家 → (13,11) → 北の畑の西の端 → y 6 を東の端まで → x 40 を南へ → y 28 を東の端まで → x 62 を南へ y 40 まで → y 40 を西へ x 50 まで → y 34 を西へ x 30 まで → y 40 を西の端まで → x 2 を北へ → 家（石 69 個） |

- 通り道を歩き、上下4マス以内に見える物を取る。y 1 の草だけは上5マス目。
- カマは、草が3つ以上まとまった所で振る。刈って空いた所にも入り、続けて振る。刈り残しは帰りに素手で拾う。振る所の細かい順は決めない。2つから振ると、計算で 38 秒遅くなり、体力も足りない。
- 道から離れている物：片付け2の囲いの中の草 (19,24)・(19,25)、片付け3の石 (10,35)。
- 石はハンマーで割る。手で運んで帯の外へ置く形は、失うマスが多く（87 マス）、時間はほぼ同じで、置き先を覚えることになる。
- 片付けずに残す物（取っても増えるマスがほとんどない草・石と、右上の耕さない所）は、地図に赤い枠で出ている。大岩は割らない。
- 片付け3でクワに持ち替えておくので、耕す1日目に納屋へ寄らなくてよい。

- 同じ日の線は、上から順に続けて回る。
- 1日に振れるのは、右下の力の木の実を取るまで 50 回、取ったあと 54 回。右の畑の西の帯・下（52）は実のあとでないと入らないので、右下を1日目にする。
- 2日目からは北の畑・中から時計回りにする。コロボックルの洞窟は南の畑から近いので、洞窟に寄る後ろの日（耕す3〜7日目）が南に来る。北の畑・西は最後の日に南の畑・西と組む（時計回りのままだと南の4本が2日に収まらない）。
- お金や力の木の実で振りが途中で終わったら、同じ所でもう1回振る。
- 耕す6日目は、帰りに納屋でハンマーを牧草の種に持ち替え、囲いの中の2区画に牧草の種をまく（牛の分の 18 マス）。
- 耕す7日目は、納屋で牧草の種をトマトの種に持ち替え、洞窟の帰りに種グリッチをする（[作物と手伝いの出荷](17_仕組み_作物と手伝いの出荷.md)）。
- 洞窟のあとは、歩いて帰るよりソフトリセットで家に戻るほうが約 1.5 秒速い。

## 5. 注意

- 耕す3日目（x 42）の始めは、大岩 (39,20)〜(40,21) で立ち位置を確かめる。大岩との間に1マス空いていれば合っている。大岩のすぐ右に立つと1列ずれ、右の端に縦1列の耕し残しが出る。
