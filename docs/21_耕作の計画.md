# 耕作の計画

2年目の秋1日から秋9日まで、片付け2日と耕す7日で、耕した広さ 1600 を超える計画です。線の引き方は何通りもあるので、ここでは何を大事にして決めたかと、実際に決めたやり方をまとめます。仕組み（クワの1振り、体力、畑の広さ）は [耕作と片付け](13_仕組み_耕作と片付け.md)、通しのルートは [ルート](20_ルート.md) にあります。

畑の地図は、チャート https://mogg-rta.github.io/harvestmoon-gb/ の2年目の各日で見られます。日ごとの線、お金や物が出る目印、片付ける物を地図に重ねて表示します。

## 1. 方針

1. 最適解は求めない。シンプルで再現性の高い線にする。
2. 同じ型を繰り返して、覚える手を少なくする。型は、縦の1本の線を往復しながら両側へ振ること。行きは1行ごとに片側へ、帰りは反対側へ振り、帰りは6行ごとに進む向きにも振って線の上も耕す。1往復で幅 13 マスの帯が耕せる。
3. 並べ方は右下から時計回りに一周する。覚えやすく、1日の終わりが家の近くになる。
4. 1600 に余りを持たせ、1〜2振りの失敗では足りなくならないようにする。今の線で、評価の見込みは 1633。
5. 振りの効率は詰めない。草・石で6マス目の手前で止まる振りがあってもよい。
6. 草・石・切り株は、耕す日より前の別の日に片付ける。耕す日は振るだけにする。
7. 家の囲いの杭は外さない。
8. 線は手で組む。耕すマスの数、振りの回数、体力が足りるかは、組んだ線を確かめるために数えるだけで、計算でいちばんよい線を探すことはしない。

## 2. 座標

座標は (x, y) で、マップの左上が (0, 0)。x は右（東）へ、y は下（南）へ増える。「y 24→44」は、y 24 から y 44 へ向かって歩くこと。

## 4. 片付けの2日

道具の持ち替えに時間がかかるので、1日の中は道具ごとにまとめて片付けます。日ごとに、耕す日の帯で分けています。

| 日 | 帯 | 順 |
| --- | --- | --- |
| 片付け1（秋1日） | 耕す4〜6日目（北の畑、南の畑の西と中） | 納屋でハンマーとスーパーオノを取り出す → 素手で草 → スーパーオノで切り株すべて → ハンマーで石 |
| 片付け2（秋2日） | 耕す1〜3日目と7日目（右の畑、南の畑の東） | 納屋でスーパーオノをスーパークワに持ち替える → 素手で草 → ハンマーで石 → スーパークワで力の木の実 (55,39) |

- 片付け1日目は 23 時より前に寝る。草を2日に分けたのは、1日目を短くして早く寝るため。
- 2日目のうちにクワへ持ち替えておくので、耕す1日目にクワを取りに行かなくてよい。
- 片付けずに残す物：牧場の端の柵に接する石、北の畑の左上の角で石と大岩に囲まれた草（もう一度素手に持ち替えることになるため）、大岩（[ルート](20_ルート.md) の 4.）。どれも地図に出ている。

## 5. 注意

- 7日目（x 42）の始めは、大岩 (39,20)〜(40,21) で立ち位置を確かめる。大岩との間に1マス空いていれば合っている。大岩のすぐ右に立つと1列ずれ、右の端に縦1列の耕し残しが出る。
- 雨のあとに、耕したマスの上をスーパークワで通らない。湿った耕し地を通ると累計が増え、目印と評価の数がずれる。
