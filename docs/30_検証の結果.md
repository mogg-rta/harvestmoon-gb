# 検証の結果

日本語版の実機（Game Boy Player、ゲームキューブのコントローラー）で確かめたこと・測ったことのうち、走りの判断に役立つものをまとめました。測ったのは 2026年11月です。仕組みの資料と重なるものは結果と数だけにして、仕組みはリンク先に任せます。最後に本番の記録を置きます。

## 1. 時計グリッチ

仕組みと手順は [時計グリッチとスーパークワ](11_仕組み_時計グリッチとスーパークワ.md) にあります。

- 日本語版の実機で成功しました。タイマーの窓で YES を A で決めるのと同じフレームにソフトリセットを入れ、つづきから始めると、経過時間の画面から日が飛びます。
- 押し方：B・スタート・Y（GB のセレクト）を押さえたまま A を押すと、YES とソフトリセットが同じフレームに入りました。
- この手でコロボックルに預けたクワを受け取り、スーパークワとスーパーカマが同時に手に入りました。
- 失敗は2種類あります。

| 失敗 | 見え方 | 原因 |
| --- | --- | --- |
| 手伝いが始まった | 経過時間の画面が出るが、経過がほぼ 0 時間 | A が先に通った。または、時計が 0 に戻ってから1分たっていない |
| 先にリセット | 経過時間の画面が出ず、家から始まる | リセットの4つが A より先にそろった |

- 時計が 0 に戻ってから（New Game、YES、経過時間の画面）60 秒たてば、確実に飛ばせました。失敗のあとは、つづきから始めて 70 秒ほど待ってからやり直します。
- 走りでは「最後のソフトリセット（岩グリッチ）から1分」を目安にしていて、これで成功しています。
- 春1日 7:00 から飛ばすと、経過時間の画面は「2855じかん」で冬30日 6:00 になりました。上限の 2880 時間が入り、年末で止める処理で削られた量と合います。

## 2. 卵のグリッチ

仕組みは [卵のグリッチと出荷](12_仕組み_卵のグリッチと出荷.md) にあります。

- 日本語版の実機でも効きます。十字キーに触らず、A だけで回せました。
- 本番の1個は約 0.7 秒（約 42 フレーム）でした。卵の区間 1:01:25 で出荷 5040 です。理論上の最短は 34 フレーム（約 0.57 秒）です。
- 2羽目の鶏を売って買い直すと、次の日からグリッチに使う位置に卵を産みました。1年近くエサなしで空腹になっていても、買い直した鶏にその晩エサを入れれば翌朝に卵があります。
- 1年目の春1日に買ったエサ1袋（500G）が2年目の秋まで残り、秋9〜13日の晩に2つずつ、10 回入れられました。
- 1日の分は、468 個までなら所持金が増えます。ルートの 400 個 ×4日で 99999G に届きました。

## 3. 鶏と牛の値段と牧草

仕組みは [幸福度・家畜・増築](14_仕組み_幸福度・家畜・増築.md) の 5. にあります。

## 4. 牧草の種を増やす手

- 牧草の種をまいている途中にソフトリセットすると、種が増えました。つづきから始めて、牧草を 10 回以上まけました。
- まき続けると、やがて種はなくなりました（2026-11-16。回数は数えていません）。コードの読みどおり、0 個から1個減って 255 回分になります。

## 5. 岩グリッチとコロボックル

仕組みは [幸福度・家畜・増築](14_仕組み_幸福度・家畜・増築.md) の 3. にあります。

- 日本語版でも効きます。リセットしても、その日の出荷とお金は消えませんでした。
- 岩を割った日は、洞窟でそのままコロボックルに話しかけられませんでした。次の日に話します。
- 同じ日に続けて話すと、あいさつ、カマの話、クワの話の3段とも進みました。
- 岩を 12 回たたいた走りで、2年目の評価の幸福度は 255（上限）でした。1:46:00 の本番も 255 です。

## 6. 評価と年越し

- 1年目の評価は、出荷が C でも鶏2羽の B だけで畑が広がりました。
- 耕したマスは冬30日まで残りました。

## 7. 増築とハンマー

仕組みは [幸福度・家畜・増築](14_仕組み_幸福度・家畜・増築.md) の 6. にあります。

- 冬に増築を頼んだあと、工事の進まない晩はありませんでした。
- 2回目の増築は、支払ったあと時計グリッチで飛ばしても、飛ばしの中で完成しました（ウルトラデラックス木の家）。
- 1回目の増築が終わると、普通のハンマーがスーパーハンマーに置き換わりました。

## 8. 動きの速さと畑

耕作の組み方は [耕作と片付け](13_仕組み_耕作と片付け.md) と [耕作の計画](21_耕作の計画.md) にあります。

| 確かめたこと | 結果 |
| --- | --- |
| 畑を歩く速さ | 10 マス／秒（1マス 6 フレーム） |
| ソフトリセットから家の入口まで | 約 8 秒 |
| ソフトリセットと耕したマス | リセットして続きから始めても、耕したマスは残る |
| 家の囲いの杭 | 飛び越えられる。どこからでも畑へ出られる |
| 向きを変える | 歩かずに向きだけ変えられる |
| スーパークワの振りのあと | すぐ次の振りや歩きに移れる |
| 牧草の上 | 歩ける。クワを振るとエフェクトは出るが、何も起きない |
| 道 | クワで耕せない |
| 草・石・切り株の配置 | New Game のたびに同じ |
| 草 | 持ち上げると空き地になる |
| 石 | 持ち上げてもおろした所へ動くだけ。なくすにはハンマーが要る |
| 片付けの回数 | 小さい石はハンマー1回、切り株はスーパーオノ1回 |
| 片付けの時間 | ハンマー、スーパーオノ、草を持ち上げて落とすのは、どれも1回 約1秒 |
| 道具の持ち替え | 素手とハンマーの持ち替えは1回 約5秒。道具ごとにまとめて片付ける |
| 割ったあとのマス | 空き地になり、歩ける |
| 体力 0 | 約5秒の動作が出る |
