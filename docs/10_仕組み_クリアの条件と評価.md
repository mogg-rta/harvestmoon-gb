# 仕組み：クリアの条件と評価

牧場物語GB（日本語版）で、牧場主になってスタッフロールに入る条件と、毎年の冬30日の評価の判定をまとめた資料です。中身は逆アセンブルの読みで、実機で確かめた所はそう書いています。

## 1. 番地の書き方

この資料とほかの資料の番地・ラベル・RAM の場所は、日本語版 GB と英語版 GBC の逆アセンブル（出典）によります。

- 番地は「bank:番地」で書く（例：10:523d は bank 10 の $523d）。RAM は「$B8F2」のように書く。
- 断りがなければ日本語版 GB の番地。英語版 GBC の番地には「英語版 GBC の」と添える。
- 英語版 GB（GBC ではない版）の話は、動画から読んだ値と推測による。

## 2. 結論

- スタッフロールに入るのは、冬30日の評価で牧場主になったときだけ。
- 評価は毎年行われ、条件がそろわなければ次の年へ続く。牧場主になれるのは早くて2年目の評価。1年目に牧場主になれないのは、1年目に取れる力の木の実が5個までで、6個に届かないから。

牧場主になる年の冬30日にそろえるものは、次のとおり。

| 条件 | 値 |
| --- | --- |
| 牛 | 4頭 |
| 鶏 | 4羽 |
| 耕した広さ | 1600 以上 |
| 出荷の累計 | 5000 以上 |
| 家 | 最大の増築 |
| 力の木の実 | 6個以上 |
| 幸福度 | 250 以上 |
| 所持金 | 65536G 以上 |
| コロボックルの時間 | 240 時間以内 |

## 3. 評価の判定

評価は毎年の冬30日の朝のイベント（番号 $11）で起きる。判定は 10:523d〜10:5467（英語版 GBC の CheckRanchMasterEligibility にあたる）。

### 5つの項目

それぞれ A・B・C の3段階で採点する。

| 項目 | RAM | A | B | C |
| --- | --- | --- | --- | --- |
| 牛の数 | $B949 から4枠（$16 おき、$FF が空き） | 4頭 | 2〜3頭 | 0〜1頭 |
| 鶏の数 | $B9A7 から4枠（$0C おき） | 4羽 | 2〜3羽 | 0〜1羽 |
| 耕した広さ | $CC9B〜$CC9C（評価のときにマップを数える） | 1600 以上 | 800 以上 | 800 未満 |
| 出荷の累計 | $BA35〜$BA37（3バイト、年をまたいで足す） | 5000 以上 | 1500 以上 | 1500 未満 |
| 家の大きさ | $CBE8 から表を引く | 最大の増築（ウルトラデラックス木の家） | 未確認 | 未確認 |

- 耕した広さは累計ではなく、評価の時点で耕されているマスの数。数に入るマスは [耕作と片付け](13_仕組み_耕作と片付け.md) にある。
- 出荷は 5000 以上で A。Web の攻略資料には 4500 とあるものがあるが、コードでは 5000。
- 家の B と C の段の分け方は読んでいない。

### 判定の順番

1. 5項目がすべて A なら、次の条件をすべて見る。満たせば牧場主になり、エンディングへ進む（2. のごほうびより先に見る）。
   - 力の木の実が6個以上（$B904）
   - コロボックルの時間（$BA10〜$BA11）が 240 時間以下（240 時間ちょうどは通る）
   - 幸福度（$B8F2）が 250 以上
   - 所持金が 65536G 以上（3バイトの一番上のバイトが 0 でない）
   - まだ牧場主になっていない（$B8D1 が 0）
2. エンディングに進まなければ、ごほうびを1年に1つ、次の順でもらう。
   1. C が5つでなければ：畑を広げる
   2. C が1つ以下なら：釣り竿
   3. A が4つ以上なら：ツルハシ
   4. A が5つなら：傘
   - 全部もらったあとは、1. の条件だけを見る。
3. どれも満たさなければ、何も起きない。

- 牧場主になるとき、主人公の性別（$B8EC）で $CCA6 に入る値が分かれる（男の子 $0B、女の子 $0C）。エンディングの文の選び分けとみる（推測）。
- 牧場主にならずにスタッフロールに入る段階は、この処理には無い。Web の攻略資料にある「称号なしでスタッフロール」は、少なくとも日本語版 GB と英語版 GBC のコードには無い。

### 1年目の評価で畑が広がる条件

- 5項目のうち C が5つでなければ、つまり1つでも B 以上があれば、1年目の評価で畑が広がる。
- 広がる土地の広さは [耕作と片付け](13_仕組み_耕作と片付け.md) にある。

## 4. コロボックルの時間（240 時間以内）

- $BA10〜$BA11 は、コロボックルの手伝い（RTC の経過時間）で過ぎた時間の合計。条件は 240 時間以下。
- 時計グリッチで日を飛ばすと、飛んだ時間がここに足される。評価の場面の終わりに 0 に戻る（bank 10 の評価の処理）ので、牧場主にならない年に何時間飛んでも、次の年の条件は壊れない。
- 判定は2か所（10:53d9 と 10:5417）にあり、どちらも $BA11（上のバイト）が 0 で、$BA10 が $F1（241）未満なら通る。240 時間ちょうどは通る（実機でも、ちょうど 240 時間でエンディングに入った）。
- 経過時間は、年末の冬30日 6:00 で切られ、時の単位で数える（分は捨てる）。牧場主になる年に冬20日の 6:00〜6:59 に飛ぶと、ちょうど 240 時間になる。7:00 以降なら 239 時間以下。
- 足され方と時計グリッチの仕組みは [時計グリッチとスーパークワ](11_仕組み_時計グリッチとスーパークワ.md)。
