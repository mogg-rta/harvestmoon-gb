# ルート

2026-11-23 の 49:50 で走ったルートの要点です。走るときの手順は [チャート](https://mogg-rta.github.io/harvestmoon-gb/) にあり、2年目の片付けと耕作の線は [耕作の計画](21_耕作の計画.md) にまとめています。

## 1. 方針

1. 出荷 5000 とお金は、2年目の時計グリッチの中でコロボックルにトマトを出荷させて作る。卵のグリッチ（約 1 時間）を使わない。仕組みは [作物と手伝いの出荷](17_仕組み_作物と手伝いの出荷.md) にある。
2. 牧場主になるのは3年目の冬30日の評価にする。2年目の評価では条件がそろわないが、そのまま3年目へ続く。
3. 寝る晩を減らす。1年目の残り、2年目の夏から冬、3年目の冬の終わりは、時計グリッチで飛ばす。
4. 再現性を優先する。片付けと耕作は最適解を求めず、見える範囲の中で次の動きが決まる形にする。数秒の差なら、覚えやすいほうを取る。

## 2. 変わらない条件

- ゴールは冬30日の評価で牧場主になり、スタッフロールに入ること。条件は [クリアの条件と評価](10_仕組み_クリアの条件と評価.md) にある。評価は毎年行われ、条件がそろわなければ次の年へ続く。
- 1年目の冬30日の評価で畑が広がる。広がった土地も使わないと、耕した広さ 1600 に届かない。
- 日本語版のスーパークワは、クワを預けてから時計で 24 時間たたないと返らない。RTA の中では、時計グリッチで時間を飛ばして受け取る（[時計グリッチとスーパークワ](11_仕組み_時計グリッチとスーパークワ.md)）。
- コロボックルの時間の条件（240 時間以内）を見るのは、牧場主になる3年目の評価だけでよい。時間は評価のたびに 0 に戻る。3年目は冬20日の朝に飛んで、ちょうど 240 時間にする。

## 3. 流れ

| 区間 | すること |
| --- | --- |
| 1年目 | 春1日：女の子で始め、家の南東 6×6 を耕して牧草をまく（種はまく途中のソフトリセットで増やす）。左の畑の力の木の実4個。引き出しの 1000G。寝て地震の日へ。地震の日：岩グリッチ 10 回。女神の泉でスーパーオノ。町でトマトの種1袋と鶏2羽。次の日：コロボックルに3回話してカマとクワを預け、時計グリッチで冬30日へ。評価で畑が広がる |
| 2年目 春 | 春1〜3日に片付け、春4〜10日にスーパークワで耕す（1634 マス）。春6〜10日は帰りに洞窟でキノコを渡す。春10日にトマトの種で種グリッチ。春11〜30日は寝る |
| 2年目 夏1日 | トマトを 97 回まく（854 マス）。時計グリッチで冬30日へ飛ぶ間に、トマトが 6 回収穫・出荷される。評価では牧場主にならない |
| 3年目 | 春1日：牛4頭・鶏2羽・材木 300 本を買い、1回目の増築を頼む。春2日に支払う。寝て冬19日へ（107 晩）。2回目の増築を頼み、冬20日の朝に支払って時計グリッチで冬30日へ。評価で牧場主 |

## 4. 決めたこと

| 中身 | 決めたこと | 理由 |
| --- | --- | --- |
| 主人公 | 女の子 | 牧草の種が1回分用意されている。まく途中のソフトリセットでこの種を増やせるので、種を買わずに春1日から牧草をまける |
| 1年目の評価 | 鶏2羽だけで畑を広げる | 5項目のどれか1つを B にすれば広がる。耕地はスーパークワが要るので1年目には耕さず、出荷は2年目のトマトで作る。鶏は2羽買えば B になる |
| 1年目の買い物 | 地震の日に、トマトの種1袋（200G）と鶏2羽（1000G） | 春1日の 1500G から買える。エサは買わない（卵を使わないので、鶏は評価の数に入ればよい）。トマトの種は、2年目に種グリッチで増やす元になる |
| 幸福度 | 岩グリッチを 10 回にする | 内訳は岩 100、牛 80、鶏 40、耕地 25、増築 10 で 255。評価の 250 に 5 の余り（[幸福度・家畜・増築](14_仕組み_幸福度・家畜・増築.md)） |
| コロボックル | 地震の次の日に3回話す（力の木の実、カマ、クワ） | 岩を 10 回たたくと好感は上限 99 になり、クワを預ける条件（50 以上）に一晩で届く |
| 好感 | 耕す3〜7日目の帰りに洞窟でキノコを渡す（5 回、話さず渡すだけ） | 夏1日の好感が 33 になり、30 以上なのでコロボックルが6日働いて1日休む。収穫は 6 回。60 以上・90 以上をねらうと、洞窟に通う回数が増える分のほうが、まくマスが減る分より大きい |
| トマト | 97 回・854 マス | 6 回の収穫で 5124 個。要る 834 マスより 20 マス多く、まき損じに備える |
| トマトのまき方 | 行ごとに、石にぶつかるまで進んで折り返す | 目印のない格子をたどる形は、走りの中で進めにくかった |
| 2年目の評価 | 牧場主にならないまま3年目へ | 牛・鶏・増築のお金はトマトの代金で作るので、2年目のうちには買えない |
| 3年目の買い物と1回目の増築 | 春1日 | 1回目の増築が春に終わる分、残りの晩を近いベッドで寝られる。小屋に置いたままの牛は病気にならない（[幸福度・家畜・増築](14_仕組み_幸福度・家畜・増築.md)） |
| 2回目の増築 | 冬19日に頼み、冬20日の朝に支払ってすぐ時計グリッチ | 2段階目の家で寝る晩を作らない。冬20日の 6 時台に飛ぶと、コロボックルの時間がちょうど 240 時間になる |
| 片付け | 3日に分け、1日1種類の作業にする | 体力の要る量が計 341 で、1日 150〜160 に収まらない。日を増やしても寝る晩は増えない |
| 耕す日 | 7日 | 8日・9日にすると覚えやすいが、1日増えるごとに約 8 秒増える |
| 大岩 | 割らない | 割る手間に見合うほどマスが増えない |

## 5. お金

| 時点 | 所持金 | 中身 |
| --- | --- | --- |
| 1年目 春1日 | 500G → 1500G | 引き出しの 1000G を足す |
| 1年目 地震の日 | 300G | トマトの種 200G、鶏2羽 1000G |
| 2年目 春 | 950G | 耕すと出るお金（計 650G） |
| 2年目 冬30日 | 99999G | トマトの代金（約 51 万G）が足されるが、所持金は 99999G で止まる |
| 3年目 春1〜2日 | 73499G | 牛4頭 20000G、鶏2羽 1000G、材木 300 本 3000G、1回目の増築 2500G |

材木は、片付けの1日目に切り株 19 個を割って 114 本（1個 +6）。1回目の増築の 100 本はここから出し、2回目の 300 本は残り 14 本に 300 本を買い足す。
