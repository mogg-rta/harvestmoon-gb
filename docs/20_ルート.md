# ルート

2026-11-14 の 1:46:00 で走ったルートの要点です。走るときの手順は [チャート](https://mogg-rta.github.io/harvestmoon-gb/) にあり、2年目の耕作の線は [耕作の計画](21_耕作の計画.md) にまとめています。

## 1. 方針

1. 危ない区間を先に済ませる。時間のかかる卵のグリッチ（約 1 時間）は、時計グリッチと耕作が終わったあとに置く。卵より前で失敗して再走になっても、失う時間が小さい。
2. 再現性を優先する。耕作は最適解を求めず、毎日同じ形の線（家の高さから外へ出て戻る縦の線）で組む。
3. 寝る晩を減らす。1年目の残りと2年目の冬の終わりは、時計グリッチで飛ばす。
4. 数え違いに余裕を持たせる。卵は1日 468 個が上限なので、2日目からは 400 個にする（68 個まで数え違えても超えない）。

## 2. 変わらない条件

- ゴールは2年目の冬30日の評価で牧場主になり、スタッフロールに入ること。条件は [クリアの条件と評価](10_仕組み_クリアの条件と評価.md) にある。
- 1年目の冬30日の評価で畑が広がる。広がった土地も使わないと、耕した広さ 1600 に届かない。
- 日本語版のスーパークワは、クワを預けてから時計で 24 時間たたないと返らない。RTA の中では、時計グリッチで時間を飛ばして受け取る（[時計グリッチとスーパークワ](11_仕組み_時計グリッチとスーパークワ.md)）。
- 時計グリッチで飛ばせる量は、コロボックルの時間の条件（240 時間以内）に収める。2年目は冬21日から飛ばして約 215 時間。

## 3. 流れ

| 区間 | すること |
| --- | --- |
| 1年目 | 春1日：女の子で始め、引き出しの 1000G。家の南東 6×6 を耕して牧草をまく（種はまく途中のソフトリセットで増やす）。左の畑の力の木の実4個。町で鶏2羽とエサ1袋。寝て地震の日へ。地震の日：岩グリッチ 12 回。女神の泉でスーパーオノ。次の日：コロボックルに3回話してカマとクワを預け、時計グリッチで冬30日へ。評価で畑が広がる |
| 耕作 | 寝て秋1日へ（60 晩）。片付け2日、スーパークワで耕す7日（1633 マス）。秋9日に2羽目の鶏を売って買い直す |
| 卵 | 秋10日に 3400 個、秋11〜14日に 400 個ずつ。秋14日は、その晩の収入が入る前に牛4頭・鶏2羽・材木 300 本を買う。出荷 5000 |
| 最後 | 秋15・16日に1回目の増築。寝て冬20日へ。2回目の増築を頼み、冬21日に支払って時計グリッチで冬30日へ。評価で牧場主 |

## 4. 決めたこと

| 中身 | 決めたこと | 理由 |
| --- | --- | --- |
| 主人公 | 女の子 | 牧草の種が1回分用意されている。まく途中のソフトリセットでこの種を増やせるので、種を買わずに春1日から牧草をまける |
| 1年目の評価 | 鶏2羽だけで畑を広げる | 5項目のどれか1つを B にすれば広がる。消去法で鶏にする。耕地はスーパークワが要るので1年目には耕さず、出荷は卵のグリッチを最後に回すので上げない。鶏は春1日に2羽買えば B になる |
| 幸福度 | 岩グリッチを 12 回にする | 内訳は岩 120、牛 80、鶏 40、耕地 25、増築 10、鶏を売る −20 で、上限 255 に止まる。評価の 250 に余裕を持って届く（[幸福度・家畜・増築](14_仕組み_幸福度・家畜・増築.md)） |
| コロボックル | 地震の次の日に3回話す（力の木の実、カマ、クワ） | 岩を 12 回たたくと好感は上限 99 になり、クワを預ける条件（50 以上）に一晩で届く |
| 卵のグリッチの時期 | 2年目の耕す7日のあと（秋10〜14日） | 1. の方針の1 |
| 卵の割り振り | 3400＋400×4 | 715 個以上出した日は、その日の売上が −15536G として入り、所持金は 0G より下にならない。なので 3400 個の日は所持金 0G のときに済ませ、失うものをなくす。あとの4日で合わせて 1387 個以上あれば、評価の 65536G に届く（400 個 ×4 なら 213 個の余り。[卵のグリッチと出荷](12_仕組み_卵のグリッチと出荷.md)） |
| 卵の鶏 | 秋9日に2羽目を売って買い直す | 1年近くエサなしで空腹の鶏も、買い直せば空腹でなく、次の日からグリッチの位置に卵を産む。3晩エサを食べさせるより速い。幸福度は −20 |
| エサ | 1晩に2つ。エサだけのために外へ出る日は作らない | 1羽目から順に食べ、卵のグリッチは2羽目の巣を使う |
| 1回目の増築 | 卵のあと（秋15日に頼み、秋16日に支払う） | 1年目に済ませても、1段階目の家で寝るのは1晩 約 0.1 秒速いだけで、増築の手間（約 1 分）を取り返せない。増築で手に入るスーパーハンマーは、大岩を割らないので要らない。片付けの石 70 個は、普通のハンマーなら体力 140 で1日に収まるが、スーパーハンマー（1回 体力 3）だと 210 で収まらない |
| 牛・鶏・材木の買い物 | 卵の最終日（秋14日）に、その晩の収入が入る前 | 所持金は 99999G で止まる。収入のあとに買うと、上限で切り捨てられた分だけ損をする。秋14日の朝の 84000G から買えば上限に届かない |
| 2回目の増築 | 冬20日に頼み、冬21日に支払って時計グリッチの飛ばしの中で完成させる | 2段階目の家で寝る晩を作らない |
| 片付け | 2日に分ける | 1日にまとめると時間がかかりすぎて、寝るのが遅くなる。遅く寝ると次の日の体力が戻りきらない（[日の進みと寝ること](15_仕組み_日の進みと寝ること.md)） |
| 大岩 | 割らない | 今の線で1個割っても、増えるマスは 0〜12、減る振りは 0〜2 回。割る手間（6回で約 5 秒、体力 12）に見合わない |

## 5. お金

| 時点 | 所持金 | 中身 |
| --- | --- | --- |
| 1年目 春1日 | 500G → 1500G → 0G | 引き出しの 1000G を足す。鶏2羽 1000G、エサ1袋 500G を買う |
| 2年目 秋9日 | 0G | 鶏を売って +500G、買い直して −500G。エサは1年目の袋を使う |
| 秋10〜13日 | 0G → 84000G | 3400 個の日は 0G のまま。400 個 ×3日で 84000G |
| 秋14日 | 84000G → 88000G | 牛4頭 20000G、鶏2羽 1000G、材木 300 本 3000G を買ってから、400 個の収入 28000G が入る |
| 冬21日 | 80500G | 増築の 2500G・5000G を引く。牧場主の条件 65536G に 14964G の余り |

材木は、片付けの1日目に切り株 19 個を割って 114 本（1個 +6）。1回目の増築の 100 本はここから出し、2回目の 300 本は残り 14 本に 300 本を買い足す。

## 6. つまずいたとき

| 場面 | 起きること | 立て直し |
