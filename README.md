## ルール

speedrun.com のルールに沿っています。

- カテゴリ：Any%（言語は Japanese）
- 計測の開始：New Game を選んだとき
- 計測の終了：スタッフロールが始まったとき
- グリッチ：すべて可
- 機種：Game Boy、Game Boy Player、エミュレータ（BizHawk 2.8 以上、Gambatte コア）

## ルートの柱

手伝いのトマトの出荷：時計グリッチ（[時計グリッチとスーパークワ](docs/11_仕組み_時計グリッチとスーパークワ.md)）で飛ばした日も、コロボックルが畑のトマトを育てて出荷します。2年目の夏1日にトマトを植えて飛び、牧場主の条件の「出荷 5000」とお金を一度に作ります。卵のグリッチ（約 1 時間）が要らなくなりました（[作物と手伝いの出荷](docs/17_仕組み_作物と手伝いの出荷.md)）。
