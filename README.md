## ルール

speedrun.com のルールに沿っています。

- カテゴリ：Any%（言語は Japanese）
- 計測の開始：New Game を選んだとき
- 計測の終了：スタッフロールが始まったとき
- グリッチ：すべて可
- 機種：Game Boy、Game Boy Player、エミュレータ（BizHawk 2.8 以上、Gambatte コア）

## ルートの柱

1. 時計グリッチ：今回新しく見つけたグリッチです。日本語版の RTA で課題だったスーパークワの入手ができるようになりました（[時計グリッチとスーパークワ](docs/11_仕組み_時計グリッチとスーパークワ.md)）。
2. 耕作手順の最適化：牧場主の条件の「1600 マスの耕作」を満たすため、片付け2日と、スーパークワで耕す7日の手順を計画しました（[耕作の計画](docs/21_耕作の計画.md)）。
